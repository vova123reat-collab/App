# Real-Life RPG — Тіло та Навички

Мобільний застосунок (PWA): білок/вода → баф XP, метод «20 годин на навичку» з ШІ-деконструкцією (Gemini), щоденні квести з HP.

Стек: Next.js 15 (App Router) · Tailwind 4 · Zustand (офлайн-стан у localStorage) · Supabase (синхронізація) · Gemini (`@google/genai`) · Vercel.

## Запуск локально

```bash
npm install
cp .env.example .env.local   # заповнити ключі
npm run dev
```

Без ключів Supabase застосунок працює локально (індикатор «локально»). Без `GEMINI_API_KEY` кроки навички вводяться вручну.

## Supabase

1. SQL Editor → виконати `supabase/schema.sql`.
2. Authentication → Providers → увімкнути **Anonymous sign-ins** (кожен телефон отримує свого користувача без реєстрації).
3. Скопіювати URL та anon key у `.env.local` / Vercel env.

Стан персонажа зберігається одним JSON-документом у `player_state` (офлайн-перше: локальна зміна → пуш через 1.5 с, при старті перемагає новіша версія). Фокус-сесії додатково пишуться в `focus_sessions` для статистики.

## Vercel

Імпортувати репозиторій, додати змінні `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `GEMINI_API_KEY`, `GEMINI_MODEL`. Ключ Gemini лише серверний — використовується в `app/api/deconstruct/route.ts`.

## На телефон

Відкрити сайт → «Додати на головний екран» (iOS Safari: Поділитися → На початковий екран; Android Chrome: меню → Встановити застосунок).

## Ігрові правила (`lib/game.ts`)

- Ціль білка = вага × 1.6 г, води = вага × 33 мл (налаштовується в профілі — тап по аватару).
- Закрив обидві норми сьогодні → завтра баф **x1.25 XP**.
- 1 хв фокусу = 1 XP (× баф) у INT або STR навички. 20 годин = 1200 хв, 4 етапи: 1–3, 4–8, 9–15, 16–20 год.
- Квест: +15 XP і +2 HP; кожен пропущений квест за минулий день: −5 HP.
- Рівень: сумарний XP за кривою `25·(L−1)·(L+4)`.
